Bose Professional · Audio systems dashboard

Dashboard UI

A dashboard concept for Bose Professional's audio systems integrators: real-time monitoring, quick control and detailed device management.

View on Behance ↗
Role
Product designer, end to end
Tools
Figma, Illustrator, React + Tailwind
Deliverables
Dashboard UI, Design system, Custom icons, Prototype

The challenge

Integrators look after many audio devices across halls, lobbies and conference rooms at once. When something goes wrong they need to see it immediately, read latency, CPU, throughput and uptime at a glance, and act on mute, reboot or diagnostics without digging through menus or logs.

Approach

  1. Start from the urgent momentDesign for the integrator who just got an alert: what do they need to see first, and what do they need to press?
  2. One screen, five jobsKPI cards, a system map, recent alerts, quick actions and a device table, each answering one question.
  3. Details carry the meaningMost of the time went into micro-interactions, button states and warning symbols, with one colour code across the product: red for errors, orange for warnings, green for success.
  4. Build it properlyA design system and prototype in Figma, eight custom icons in Illustrator, and a visual concept in React and Tailwind.

The solution

A single control hub for system health.

  • At-a-glance cards surface latency, CPU, uptime and throughput at the top, so something off is spotted in seconds
  • Interactive system map shows every device in one place, with errors and warnings popping out and labels that give the device name and ID
  • Recent alerts collect everything in one scrollable list, each with device, issue and time
  • Quick actions keep soft controls (mute, diagnostics) and critical ones (reboot, power off) together, one click away in an emergency
  • Device table compares name, zone, latency, CPU, status and last seen side by side
