Let's Spin

Interactive Figma prototype

A spin-the-wheel micro-interaction for a landing page, built in Figma and shared as a free community file.

Get the Figma file ↗View on Behance ↗
Role
Interaction and UI design
Tools
Figma
Deliverables
Interactive prototype, Free community file

The challenge

Landing pages often need a playful hook, like a spin-to-win offer, to hold attention. Most examples are built in code; I wanted to show how far a Figma prototype alone can go.

Approach

Interaction and UI design, prototyped entirely in Figma.

The solution

A working spin-the-wheel interaction you can try below. It's published as a free Figma community file, so other designers can open it, see how it's set up and reuse it.

Result

Published as a free Figma Community file, which other designers have duplicated 134 times.
