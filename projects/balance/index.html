The principle of Balance

Presentation · Seminar talk

A slide presentation on balance in design: visual weight and the five types of balance.

View on Behance ↗
Role
Research, writing, slides and the talk
Deliverables
Slide deck, Seminar talk

The challenge

I researched and built this deck for a seminar talk. Balance is one of the most used and least explained design principles, so the goal was to make it easy to understand for anyone, designer or not.

Approach

  1. Define itStart with a plain definition: how elements are weighted against each other so a design feels cohesive and complete.
  2. Explain visual weightShow why some shapes feel heavier than others before getting into the types.
  3. Map the five typesSymmetrical, asymmetrical, radial, mosaic and discordant, drawn as a metro map so the structure of the talk is visible.
  4. Show real examplesPair each type with a simple diagram and a brand people know, like the Starbucks siren for symmetry.

The solution

A visual deck that defines balance, explains visual weight, and walks through five types (symmetrical, asymmetrical, radial, mosaic and discordant), each shown with simple diagrams and real-world brand examples.
